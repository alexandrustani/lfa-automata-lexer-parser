# LFA — Etapa 2

Implementation for Etapa 2 of Formal Languages and Automata (LFA).

## Contents

- `src/`: automata, regular expressions, lexer, grammar, and parser implementation.
- `grammar_lambda.txt`, `lexer_spec.json`, `parser_grammar.txt`: input specifications.
- `test/`, `tests_1/`, `tests_2/`, `tests_4/`: included tests and sample inputs. Large generated test inputs and submitted archives are omitted.

## Run tests

Requires Python 3. Run `python -m unittest discover -s test` from the repository root.
